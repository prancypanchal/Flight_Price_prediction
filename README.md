# ✈️ Flight Price Prediction Using Machine Learning

## 📌 Project Overview
This project aims to predict flight ticket prices using Machine Learning techniques. It analyzes various flight-related features to understand the factors affecting ticket prices and estimate flight fares.

## 🛠️ Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 📊 Project Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Data Preprocessing
5. Feature Engineering
6. Model Building
7. Model Evaluation
8. Price Prediction

## 🤖 Machine Learning
**Problem Type:** Supervised Learning – Regression

## 📈 Evaluation Metrics
- MAE
- MSE
- RMSE
- R² Score

## 🎯 Objective
To build a Machine Learning model that predicts flight ticket prices based on different flight attributes.
